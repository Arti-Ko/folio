# Folio

Локальная вики в духе Confluence для macOS 26: страницы лежат Markdown-файлами у вас на диске, у каждого пространства своя история в git, есть поиск, ссылки между страницами и утилита командной строки.

**[⬇ Скачать Folio.dmg](https://github.com/Arti-Ko/folio/releases/latest/download/Folio.dmg)** · [все выпуски](https://github.com/Arti-Ko/folio/releases)

## Установка

1. Откройте `Folio.dmg` и перетащите Folio в «Программы».
2. Приложение не нотариально заверено Apple, поэтому при первом запуске macOS его остановит: **Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»**. Или в Терминале: `xattr -dr com.apple.quarantine /Applications/Folio.app`.
3. При первом запуске Folio предложит создать пространства «Работа» и «Личное» в `~/Folio`. Не в «Документах»: к ним macOS спрашивает доступ заново после каждого обновления неподписанного приложения.
4. Утилита `folio`: **Folio → Настройки → Командная строка → Установить**.

Требования: macOS 26 и Mac на Apple Silicon.

## Обновления

Folio сам проверяет [GitHub Releases](https://github.com/Arti-Ko/folio/releases) при запуске и каждые 6 часов. Новая версия скачивается в фоне и ставится, когда вы закрываете приложение. Чтобы обновиться сразу, нажмите «Перезапустить для версии X» внизу боковой панели.

Если в **Настройки → Обновления** выключить автоматическую установку, вместо этого появится окно с описанием изменений. Проверить вручную — **Folio → Проверить обновления…**.

## Что умеет

- **Пространства** — отдельные папки со своей историей git: рабочие материалы не смешиваются с личными.
- **Дерево страниц**: страница — папка с `index.md`, подстраницы — вложенные папки, вложения лежат рядом.
- **Элементы Confluence**: цветные панели, статусы, раскрывающиеся блоки, оглавление, список дочерних страниц, таблицы, задачи.
- **Ссылки** `[[Заголовок]]` и `[[Пространство::Заголовок]]` не ломаются при переносе, при переименовании чинятся во всех пространствах.
- **Поиск** по тексту, в том числе по части слова, обратные ссылки, вложения, история версий с просмотром старых.
- **Шаблоны**: протокол встречи, требования, техническое задание.
- **Утилита `folio`**: `tree`, `search`, `open`, `new`, `rename`, `move`, `delete`, `backlinks`, `history`, `check`, `commit`.

Визуальный редактор — в разработке.

## Формат страницы

```markdown
---
id: 3f9c2a7b1d04
title: Протокол встречи с заказчиком
status: В работе
labels: [встреча, crm]
---

:::warning {title="Нужно выяснить"}

Сроки интеграции — у [[Требования к CRM|владельца требований]].

:::

| ID   | Требование  | Статус                                  |
| ---- | ----------- | --------------------------------------- |
| FR-1 | Вход по СМС | [status color="blue"]В работе[/status] |
```

Полные правила разметки — в `CLAUDE.md`, который создаётся в каждом пространстве.

## Разработка

```sh
Scripts/build.sh              # dist/Folio.app
Scripts/build.sh --install    # в /Applications и ссылка folio в /opt/homebrew/bin
Scripts/package.sh            # dist/Folio.dmg и dist/Folio.zip
Scripts/make-icon.sh          # Assets/AppIcon.icns
Scripts/release.sh 0.2.0      # тег → GitHub Actions соберёт и опубликует выпуск
```

Тесты: `swift test` и `cd web && npm test`. Если глобальный git настроен с `safe.bareRepository=explicit`, SwiftPM нужен обход: `GIT_CONFIG_COUNT=1 GIT_CONFIG_KEY_0=safe.bareRepository GIT_CONFIG_VALUE_0=all swift test`.

Устройство: `Sources/FolioCore` — модель, индекс поиска, git, обновления; `Sources/FolioCLI` — утилита `folio`; `Sources/FolioApp` — приложение SwiftUI; `web/` — отрисовка страниц на TipTap.
